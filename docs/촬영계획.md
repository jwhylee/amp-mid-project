# 촬영 계획 — 데모 1분 + 원칙 클립

> 기준: 발표자료 10장 "데모"(1분 영상 + 원칙 클립 p0x.mp4)와 체크 항목 5개(화면 전환 · 임의 결과 · json-server GET · 로딩/오류/빈 상태 · 적응형), 부록 B2 원칙 카드의 "시연" 칸(5–10초 클립), 안내문 7장 UI 구현 25점.
> 저장 위치: `docs/영상/demo_1min.mp4` · `docs/영상/p0x.mp4` (100MB 넘으면 드라이브 링크를 README "데모" 칸에).

## 0. 촬영 준비 (매번)

```bash
cd mock_server && npx json-server --watch db.json --port 3000
```

```bash
flutter run -d macos
```

- **macOS 앱 창으로 찍는다**: 창 모서리를 끌면 적응형(600dp · 900dp)을 바로 보여 줄 수 있다. 시작할 때는 창을 폰처럼 좁게(가로 약 400) 맞춘다.
- 설정 → **발표 · 영상용(F-4)이 "평소"**인지 확인한다. 앱을 새로 켜면 항상 "평소"다.
- 클립마다 처음 상태로 돌아가려면 터미널에서 `R`(핫 리스타트)을 누른다.
- 알림 · 메신저 팝업을 끄고, 화면에 개인정보가 보이지 않는지 확인한다.
- **직접 칠 문장은 아래 두 개만 쓴다** (띄어쓰기는 달라도 된다):
  - ① `60만 원 이하 펜더 일렉, 앰프 빼고` → 결과 있음(응답 1)
  - ② `강남 주말 드럼 합주실 1만 원 이하` → 결과 없음(응답 2, 빈 상태)
  - 그 밖의 문장은 모두 ①과 같은 결과가 나온다(미리 정한 임의 결과).
