# 촬영 계획 — 데모 1분 + 원칙 클립 + 셀프 논증 '후' 캡처

> 기준: 발표자료 10장 "데모"(1분 영상 + 원칙 클립 p0x.mp4)와 체크 항목 5개(화면 전환 · 임의 결과 · json-server GET · 로딩/오류/빈 상태 · 적응형), 부록 B2 원칙 카드의 "시연" 칸(5–10초 클립), 안내문 7장 UI 구현 25점.
> 저장 위치: `docs/영상/demo_1min.mp4` · `docs/영상/p0x.mp4` (100MB 넘으면 드라이브 링크를 README "데모" 칸에) · 캡처는 `docs/screenshots/`.
> 기준 커밋: p10(AI 조언 컨설팅 · 닫기 확인 · 조건 변경 배너 · 숫자 배지 · 인사말) + 게시글 사진(db.json image · 실패 땐 카테고리 그림).

## 0. 촬영 준비 (매번)

```bash
cd mock_server && npx json-server --watch db.json --port 3000
```

```bash
flutter run -d macos
```

- **macOS 앱 창으로 찍는다**: 창 모서리를 끌면 적응형(600dp · 900dp)을 바로 보여 줄 수 있다. 시작할 때는 창을 폰처럼 좁게(가로 약 400) 맞춘다.
- `db.json`이 바뀌었으므로 json-server를 **새로 켠 뒤** 찍는다(`/aiResponses?id=3`이 나오면 최신).
- 설정 → **발표 · 영상용(F-4)이 "평소"**인지 확인한다. 앱을 새로 켜면 항상 "평소"다.
- 클립마다 처음 상태로 돌아가려면 터미널에서 `R`(핫 리스타트)을 누른다.
- 알림 · 메신저 팝업을 끄고, 화면에 개인정보가 보이지 않는지 확인한다.
- **직접 칠 문장은 아래 두 개만 쓴다** (띄어쓰기는 달라도 된다):
  - ① `60만 원 이하 펜더 일렉, 앰프 빼고` → 결과 있음(응답 1) — 컨설팅 6칸 모두
  - ② `강남 주말 드럼 합주실 1만 원 이하` → 결과 없음(응답 2) — 컨설팅은 목적 · 예산 바꾸면 · 근거만
  - 그 밖의 문장은 모두 ①과 같은 결과다(미리 정한 임의 결과). 예시 칩 3번 "베이스 레슨 초보"는 응답 3, 알림 "재즈베이스"는 응답 4.
- 게시글 사진은 db.json `image` 주소(Unsplash 악기 · 합주실 사진)를 불러온다. **인터넷이 연결된 상태**에서 찍고, 첫 화면에서 사진이 다 뜰 때까지 잠깐 기다린다(불러오는 중 · 실패 땐 카테고리 아이콘 그림이 대신 보인다).

## 1. 데모 1분 — `demo_1min.mp4` (발표자료 10장)

| 시간 | 할 것 (입력 · 누를 곳) | 화면에 보이는 것 | 10장 체크 항목 |
|---|---|---|---|
| 0:00–0:05 | 홈에서 시작 → 잠깐 멈춤 → 조금 내려 **내 알림 조건** 알약 "재즈베이스" → 다시 "펜더 일렉" | 인사말 "오늘은 어떤 음악 활동을 펼쳐볼까요?" · 게시판 바로가기 아래 낮은 새 글 카드 · 숫자 배지 "2" | json-server GET(`/alerts`) |
| 0:05–0:14 | 위로 올려 A-2 입력창에 문장 **①을 직접 입력** → 보내기 | C 시트가 덮임 · 연보라 조건 칩 · 칩 아래 "추천 결과 3개 · 장터 · 합주실" · AI 조언 접힘(목적 칩 · "1순위 · …") | 화면 전환(덮기) · 임의 결과 |
| 0:14–0:22 | AI 조언 **자세히 보기** → 천천히 내려 1순위 이유 → 비교표 → 사기 전 확인할 것 → 예산을 바꾸면 → 근거 | 컨설팅 6칸 | 임의 결과 |
| 0:22–0:31 | 비교표 첫 줄 "멕시코 스트랫" 누름 → 탭 **AI 상태 체크 → 시세** | B-8 "여는 중" → B 상세(진한 뒤로가기 바) · B-6 사진 위 제자리 번호 ①②③ · B-5 평균 눈금 + "시세 평균보다 2만 원 싸요" | 화면 전환(쌓기 · 옆으로 탭) |
| 0:31–0:34 | 뒤로(←) → 시트 오른쪽 위 **닫기(X)** | 시트로 돌아왔다가 홈으로(고친 조건이 없어 바로 닫힘) | 화면 전환(pop) |
| 0:34–0:49 | 하단 **설정** → F-4 **느리게** → 하단 **게시판** → "합주실" 탭 (3초 로딩 → 목록) → 설정 **오류** → 게시판 "레슨" 탭 (오류) → 설정 **평소** → 게시판 **다시 시도** | 로딩 표시 → 목록 → 오류 + 다시 시도 → 목록 | 로딩 · 오류 (옆으로: 하단 메뉴) |
| 0:49–0:53 | 홈 → A-2에 문장 **②** 입력 → 보내기 | "추천 결과 없음" · "조건에 맞는 글이 없습니다. 조건을 하나 빼 보세요." | 빈 상태 |
| 0:53–1:00 | 닫기(X) → 하단 **게시판** → 창을 오른쪽으로 끌어 넓힘(600 넘으면 2열, 900 넘으면 3열) | 목록 → 2열 격자 → 3열 격자 (사진이 위로) | 적응형 |

> 시간이 모자라면 0:14–0:22(컨설팅 펼침)를 3초로 줄이고, 자세한 장면은 p10 클립으로 보여 준다.

## 2. 원칙 클립 — `p0x.mp4` (5–10초, 원칙 카드 "시연" 칸)

발표자료 5장 "새로운 기능"의 P번호(P06 · P05 · P07, 근거 P10 · P01 · P04)를 **필수**로, 셀프 논증 쟁점 1 · 4 · 5와 이어지는 P03 · P02 · P08은 **권장**으로 찍는다.

| `p05.mp4` | 오류 예방 | 필수 | 빈 입력창에서 보내기가 **꺼져 있음** → 문장 ① 입력 → 결과보다 먼저 보이는 조건 칩 · 빨간 [앰프 빼기] → "+ 빼는 단어" → 빈 칸이면 "추가"가 꺼져 있음 → **`lespaul` 입력** → 추가 → 빨간 [lespaul 빼기] → (덧붙여) AI 조언 자세히 보기의 "사기 전 확인할 것" | A-2 · C-2 · C-3 · C-4 ④ |
